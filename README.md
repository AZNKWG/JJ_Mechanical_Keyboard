# JJ_Mechanical_Keyboard
My repository of my 84-key mechanical keyboard.

This is my repository for an 84-key mechanical keyboard that I can use in my daily life. The reason for making this exact type of keyboard is so that it is custom to me, and because the format of it allows me to add custom changes to it to be in a more of a style of a gamer. It has a rotary encoder as a volume knob so that it is not going to be annoying to change the volume.
